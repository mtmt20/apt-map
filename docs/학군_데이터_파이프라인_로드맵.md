# 학군 데이터 파이프라인 로드맵 (2026-09-28)

요청한 알고리즘을 돌리려면 데이터가 있어야 한다. **먼저 각 항목이 실제로 구할 수 있는지
확인한 결과를 적는다.** 추측이 아니라 전부 직접 호출·조회해서 확인한 것이다.

## 0. 조사 결과 (2026-09-28 직접 확인)

| 필요 데이터 | 판정 | 근거 |
|---|---|---|
| 3학년 전체 학생 수 | ✅ 가능 | 학교알리미 OpenAPI `apiType=10, 63` (이미 수집 중) |
| 학급당 인원·학급 수 | ✅ 가능 | `apiType=62` (이미 수집 중) |
| **교과별 학업성취 A~E 비율** | ✅ **가능(웹 공시)** | 항목별 공시 `학업성취사항 > 교과별 학업성취 사항`, 공시항목코드 **44**. OpenAPI 에는 없음(26개 apiType 전수 확인) |
| 중학교 특목·자사고 진학자 수 | ❌ 불가 | `apiType=51`(졸업생 진로) 는 "진학 99.x%" 만, 고교 유형 구분 없음 |
| 고교 대학 진학률(서울대/의약학) | ❌ 불가 | `apiType=51` 의 `TOTAL_RATE` 는 **81개교 전부 100.0**, `FOREIGN_ST_RATE` 전부 0.0. 형식값 |
| 수시/정시 구분 | ❌ 불가 | 공시 항목 자체가 없음 |
| 대회 입상 | ❌ 불가 | 공시 항목 없음 |

### 라이선스·수집 가능 여부

- `schoolinfo.go.kr/robots.txt` → `User-agent: * / Allow: /` (전체 허용)
- 저작권정책: **공공누리(KOGL)**. 유형에 따라 상업적 이용·변경 가능. **출처표시 필수**
  - 표기 예: `본 저작물은 '교육부'에서 '2026년' 작성하여 공공누리 제O유형으로 개방한
    '교과별 학업성취 사항'을 이용하였으며, 학교알리미(https://www.schoolinfo.go.kr/)에서
    무료로 받을 수 있습니다.`
  - **실제 붙일 때 각 공시자료의 공공누리 유형을 확인하고 그 유형 번호를 적을 것.**

### 하지 않기로 한 것과 이유

**1) 베리타스알파 등 입시 매체 합격 실적 크롤링 — 하지 않는다.**
`veritas-a.com/robots.txt` 는 `/admin/` 과 `/news/articleList.html` 만 막고 기사 본문은
막지 않는다. 그러나 **robots.txt 가 막지 않는 것과 써도 되는 것은 다르다.** 그 표는 기자들이
학교마다 취재해서 만든 편집저작물이고, 우리 사이트는 광고가 붙어 있다. 가져다 재게시하면
저작권 문제가 생기고, 문제 제기를 받으면 방어할 수 없다. 이 프로젝트가 네이버부동산과
법원경매를 수집하지 않는 것과 같은 기준이다.

**2) IP 차단 회피 — 하지 않는다.** 상대가 막겠다고 한 것을 뚫는 일이다.
대신 정당한 방법(요청 간격, 캐시, 증분 수집, User-Agent 명시)으로 상대 서버 부담을 줄인다.

**3) 결측 대입실적의 회귀 추정값을 화면에 올리지 않는다.**
실재하는 학교에 대해 없는 사실을 만들어내는 것이다. 내부 분석용으로 계산하는 것까지는
막을 이유가 없지만, **사이트에 노출할 때는 반드시 `추정`이라고 표시하고 계산식을 공개**해야
하며, 학교 이름과 함께 "서울대 O명" 같은 형태로는 절대 쓰지 않는다.

## 1. 아키텍처

이 프로젝트는 **DB 없이 파일로** 돌아간다(파이프라인 → JSON → 정적 사이트). 학업성취 수집도
같은 방식을 유지하되, 나중에 규모가 커지면 DuckDB 파일 하나로 옮길 수 있게 스키마를 맞춰 둔다.

```
pipeline/
  fetch_schoolinfo.py          (기존) OpenAPI - 학생수/학급당/기본정보
  fetch_achievement.py         (신규) 웹 공시 - 교과별 학업성취 A~E
  build.py                     (기존) 단지에 붙이고 점수 계산
data/raw/
  schoolinfo/                  (기존) apiType_knd_sgg_year.json
  achievement/                 (신규) <학교코드>_<연도>.json   ← 학교당 1파일, 증분 수집
  achievement_index.json       (신규) 학교코드 -> 마지막 수집일 (재수집 건너뛰기용)
```

**증분 수집이 핵심이다.** 전국 중·고 약 8천 개를 매일 받으면 상대 서버에 부담이고 우리도
느리다. 공시는 연 1~2회 갱신되므로 **연도별로 한 번만** 받고 캐시한다.

## 2. `pipeline/fetch_achievement.py` — 교과별 학업성취 수집

```python
# -*- coding: utf-8 -*-
"""학교알리미 '교과별 학업성취 사항' 공시 -> data/raw/achievement/<학교코드>_<연도>.json

  python pipeline/fetch_achievement.py --knd 03 --sido 11 --year 2026
  python pipeline/fetch_achievement.py --knd 03 --sido 11 --year 2026 --refresh   # 캐시 무시

OpenAPI 에는 이 항목이 없어(26개 apiType 전수 확인) 웹 공시를 읽는다.
robots.txt 전체 허용, 공공누리 개방 자료. 출처표시 의무가 있으므로 결과 JSON 에 함께 담는다.

예의:
  - 요청 간격 1.2초, 동시 요청 없음(단일 스레드)
  - 연 1~2회 갱신되는 자료이므로 학교·연도 단위로 캐시하고 다시 받지 않는다
  - User-Agent 에 목적과 연락처를 밝힌다 (차단 회피가 아니라 반대로 신원을 밝히는 것)
"""
import argparse
import json
import os
import re
import sys
import time

import requests
from bs4 import BeautifulSoup

HERE = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, HERE)
from fetch_trades import RAW, load_env  # noqa: E402

OUT = os.path.join(RAW, "achievement")
BASE = "https://www.schoolinfo.go.kr"
LIST_URL = BASE + "/ei/ss/pneiss_a05_s1.do"      # 항목별 공시정보 화면
SEARCH_URL = BASE + "/ei/ss/Pneiss_f01_l0.do"    # 검색 폼 action
HANGMOK_ACHIEVEMENT = "44"                        # 교과별 학업성취 사항
UA = "jipkokmap-research/1.0 (+https://jipkokmap.kr; 공공누리 공시자료 이용)"
GAP = 1.2                                         # 요청 간격(초)

SUBJECTS = ("국어", "영어", "수학")
GRADES = ("A", "B", "C", "D", "E")


class Fetcher:
    def __init__(self):
        self.s = requests.Session()
        self.s.headers.update({"User-Agent": UA, "Referer": LIST_URL})
        self.last = 0.0

    def get(self, url, **kw):
        """요청 간격을 지키고, 일시적 오류는 세 번까지 다시 시도한다."""
        for attempt in range(3):
            wait = GAP - (time.time() - self.last)
            if wait > 0:
                time.sleep(wait)
            try:
                r = self.s.request(kw.pop("method", "GET"), url, timeout=30, **kw)
                self.last = time.time()
            except requests.RequestException as e:
                if attempt == 2:
                    raise
                time.sleep(3 * (attempt + 1))
                continue
            if r.status_code == 429 or 500 <= r.status_code < 600:
                time.sleep(10 * (attempt + 1))     # 서버가 힘들다는 신호 -> 더 쉰다
                continue
            r.raise_for_status()
            return r
        raise RuntimeError("요청 실패: " + url)


def parse_achievement(html):
    """공시 HTML 에서 과목 x 성취도(A~E) 비율 표를 뽑는다.

    표 구조가 학교/연도마다 조금씩 다르므로 '헤더에서 A~E 열 위치를 찾고,
    행 머리에서 과목명을 찾는' 방식으로 읽는다. 열 순서가 바뀌어도 견딘다.
    파싱에 실패하면 예외를 던지지 말고 None 을 반환해 그 학교만 건너뛴다.
    """
    soup = BeautifulSoup(html, "html.parser")
    out = {}
    for table in soup.find_all("table"):
        head = [th.get_text(strip=True) for th in table.find_all("th")]
        col = {g: i for i, h in enumerate(head) for g in GRADES if h.startswith(g)}
        if len(col) < len(GRADES):
            continue                                   # 성취도 표가 아니다
        for tr in table.find_all("tr"):
            cells = [td.get_text(strip=True) for td in tr.find_all(["td", "th"])]
            if not cells:
                continue
            subj = next((s for s in SUBJECTS if s in cells[0]), None)
            if not subj:
                continue
            vals = {}
            for g, i in col.items():
                if i < len(cells):
                    m = re.search(r"(\\d+(?:\\.\\d+)?)", cells[i])
                    if m:
                        vals[g] = float(m.group(1))
            if len(vals) == len(GRADES):
                out.setdefault(subj, vals)
    return out or None


def fetch_school(f, schul_code, year):
    """학교 하나의 공시 페이지를 받아 파싱한다."""
    r = f.get(SEARCH_URL, method="POST", data={
        "GS_HANGMOK_CD": HANGMOK_ACHIEVEMENT,
        "SCHUL_CODE": schul_code,
        "GS_YEAR": str(year),
    })
    data = parse_achievement(r.text)
    if not data:
        return None
    return {
        "schul_code": schul_code,
        "year": year,
        "subjects": data,
        # 공공누리 출처표시 의무. 화면에 쓸 때 이 문구를 같이 노출한다.
        "source": "교육부 학교알리미 '교과별 학업성취 사항' ({}년) https://www.schoolinfo.go.kr/".format(year),
        "fetched_at": time.strftime("%Y-%m-%d"),
    }


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--schools", help="학교코드 목록 파일(줄바꿈 구분). 없으면 schools_neis.json 사용")
    ap.add_argument("--year", type=int, default=2026)
    ap.add_argument("--refresh", action="store_true", help="캐시 무시하고 다시 받기")
    ap.add_argument("--limit", type=int, default=0, help="이번 실행 최대 학교 수(0=제한없음)")
    a = ap.parse_args()
    load_env()
    os.makedirs(OUT, exist_ok=True)

    if a.schools:
        codes = [x.strip() for x in open(a.schools, encoding="utf-8") if x.strip()]
    else:
        src = json.load(open(os.path.join(RAW, "schools_neis.json"), encoding="utf-8"))
        codes = [x["code"] for x in src.get("middle", []) if x.get("code")]

    f = Fetcher()
    ok = skip = fail = 0
    for i, code in enumerate(codes):
        if a.limit and ok + fail >= a.limit:
            print("이번 실행 상한에 도달. 남은 학교는 다음에 받습니다.")
            break
        path = os.path.join(OUT, "{}_{}.json".format(code, a.year))
        if os.path.exists(path) and not a.refresh:
            skip += 1
            continue
        try:
            rec = fetch_school(f, code, a.year)
        except Exception as e:                       # 한 학교 실패로 전체가 죽지 않게
            fail += 1
            print("  실패 {}: {}".format(code, str(e)[:70]))
            continue
        if not rec:
            fail += 1
            print("  파싱 실패(공시 없음일 수 있음):", code)
            continue
        json.dump(rec, open(path, "w", encoding="utf-8"), ensure_ascii=False)
        ok += 1
        if ok % 25 == 0:
            print("  {}/{} 수집".format(ok, len(codes)))
    print("완료: 신규 {} · 캐시 건너뜀 {} · 실패 {}".format(ok, skip, fail))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

**검증이 남은 부분:** `SEARCH_URL` 의 정확한 파라미터 이름은 화면 조작으로 확인해야 한다.
위 코드는 폼 action(`/ei/ss/Pneiss_f01_l0.do`)과 체크박스 이름(`GS_HANGMOK_CD`), 항목코드(44)
까지는 실제로 확인한 값이고, 나머지 파라미터는 첫 실행에서 응답을 보고 맞춘다.
**한 학교로 먼저 시험하고(`--limit 1`) 표가 제대로 나오는지 눈으로 확인한 뒤 전체를 돌릴 것.**

## 3. `pipeline/score_calculator.py` — 표준화와 점수 산출

요청한 Z-Score 표준화와 가중합을 구현하되, **없는 데이터는 만들어내지 않는다.**
결측은 회귀로 채우지 않고 `가중치 재분배`로 처리한다. 즉 그 항목을 빼고 남은 항목의
가중치를 비례 확대한다(지금 `build.py` 의 `edu_score` 가 이미 쓰는 방식).

```python
# -*- coding: utf-8 -*-
"""학군 점수 계산. 표준화(Z) -> 0~100 변환 -> 가중합.

설계 원칙:
  1. 결측을 추정으로 메우지 않는다. 그 항목을 빼고 남은 가중치를 비례 확대한다.
     (추정으로 채우면 데이터가 부족한 학교일수록 점수가 그럴듯해지는 함정이 생긴다)
  2. 표본이 적으면 점수를 주지 않는다. n 이 작을수록 중앙값 쪽으로 당긴다(수축).
  3. 모든 점수에 `confidence` 를 같이 낸다. 화면에서 신뢰도가 낮으면 흐리게 표시한다.
"""
import math
import statistics


def zscore(values):
    """값 목록 -> {값: z}. 표준편차 0이면 전부 0."""
    vals = [v for v in values if v is not None]
    if len(vals) < 2:
        return lambda v: 0.0
    mu = statistics.mean(vals)
    sd = statistics.pstdev(vals)
    if sd == 0:
        return lambda v: 0.0
    return lambda v: 0.0 if v is None else (v - mu) / sd


def z_to_100(z):
    """z 를 0~100 으로. ±2.5σ 를 0/100 에 맞춘다(극단값에 덜 휘둘리게)."""
    return max(0.0, min(100.0, 50.0 + z * 20.0))


def shrink(score, n, k=10):
    """표본이 적으면 중앙값(50)쪽으로 당긴다. n=k 일 때 절반만 반영."""
    if not n:
        return 50.0
    w = n / (n + k)
    return 50.0 + (score - 50.0) * w


def weighted(parts):
    """parts = [(값 0~100 또는 None, 가중치)] -> (점수, 반영된 가중치 비율)

    결측은 빼고 남은 가중치로 정규화한다. 반영 비율이 낮으면 신뢰도가 낮다는 뜻.
    """
    avail = [(v, w) for v, w in parts if v is not None]
    if not avail:
        return None, 0.0
    total = sum(w for _, w in avail)
    score = sum(v * w for v, w in avail) / total
    return round(score), round(total / sum(w for _, w in parts), 2)


def a_grade_ratio(subjects, subset=("국어", "영어", "수학")):
    """국영수 A등급 평균 비율 + 난이도 보정.

    요청하신 '시험이 쉬운 학교 부풀리기 차단'을 과목 간 표준편차로 구현한다.
    세 과목이 고르게 높으면 실력, 한 과목만 튀면 난이도 문제일 가능성이 크다.
    """
    vals = [subjects[s]["A"] for s in subset if s in subjects and "A" in subjects[s]]
    if len(vals) < 2:
        return None
    avg = statistics.mean(vals)
    sd = statistics.pstdev(vals)
    return round(avg * (1 - min(sd, 100) / 100.0), 1)


def school_score(rec, pop):
    """중학교 한 곳의 학업 지표 점수.

    rec: {"subjects": {...}, "students_3": int}
    pop: 모집단 통계 {"a_ratio": [전체 학교의 보정 A비율 목록]}
    """
    a = a_grade_ratio(rec.get("subjects") or {})
    z = zscore(pop["a_ratio"])
    part = z_to_100(z(a)) if a is not None else None
    score, conf = weighted([(part, 1.0)])
    if score is None:
        return {"score": None, "confidence": 0.0, "a_ratio": None}
    return {"score": round(shrink(score, rec.get("students_3") or 0, k=60)),
            "confidence": conf, "a_ratio": a}
```

### 대입 실적을 쓰게 된다면 (출처를 댈 수 있을 때만)

요청하신 정규화·감쇄는 다음 형태가 맞다. **다만 입력 데이터가 생겼을 때만 켠다.**

```python
def admission_index(sugi, jeongsi, grade3_n, decay=0.6):
    """(수시 + 정시*0.6) / 3학년 수 * 100. 정시 감쇄는 N수생 유입 보정."""
    if not grade3_n:
        return None
    return round((sugi + jeongsi * decay) / grade3_n * 100, 2)
```

## 4. 저장 스키마

지금은 파일이면 충분하지만, 규모가 커지면 **DuckDB 파일 하나**를 권한다(서버 불필요, 비용 0).
아래 DDL 은 PostgreSQL / DuckDB 양쪽에서 거의 그대로 돈다.

```sql
-- 학교 기본 (학교알리미 apiType=0)
CREATE TABLE school (
  schul_code   TEXT PRIMARY KEY,          -- SD_SCHUL_CODE
  name         TEXT NOT NULL,
  kind         TEXT NOT NULL,             -- 초/중/고
  found_type   TEXT,                      -- 국립/공립/사립
  hs_type      TEXT,                      -- 일반고/자율고/특목고/특성화고
  sido         TEXT, sgg TEXT, emd TEXT,
  lat          DOUBLE PRECISION, lng DOUBLE PRECISION,
  updated_at   DATE
);

-- 연도별 학생/학급 (apiType=10, 62, 63)
CREATE TABLE school_year (
  schul_code   TEXT REFERENCES school(schul_code),
  year         INT,
  students     INT,
  students_g3  INT,                       -- 3학년
  classes      INT,
  class_size   NUMERIC(4,1),
  move_in      INT, move_out INT,
  PRIMARY KEY (schul_code, year)
);

-- 교과별 학업성취 (웹 공시, 공공누리)
CREATE TABLE achievement (
  schul_code   TEXT REFERENCES school(schul_code),
  year         INT,
  subject      TEXT,                      -- 국어/영어/수학/...
  a_pct NUMERIC(5,2), b_pct NUMERIC(5,2), c_pct NUMERIC(5,2),
  d_pct NUMERIC(5,2), e_pct NUMERIC(5,2),
  source       TEXT NOT NULL,             -- 공공누리 출처표시 문구 (필수)
  fetched_at   DATE,
  PRIMARY KEY (schul_code, year, subject)
);

-- 계산된 점수 (재현 가능하도록 가중치와 신뢰도를 같이 저장)
CREATE TABLE school_score (
  schul_code   TEXT REFERENCES school(schul_code),
  year         INT,
  score        NUMERIC(5,1),
  confidence   NUMERIC(3,2),              -- 반영된 가중치 비율 0~1
  weights_json TEXT NOT NULL,             -- 어떤 가중치로 냈는지
  algo_version TEXT NOT NULL,             -- 'edu_v2_2026-09-28'
  PRIMARY KEY (schul_code, year, algo_version)
);

CREATE INDEX ix_school_geo ON school (sgg, emd);
CREATE INDEX ix_ach_year ON achievement (year, subject);
```

`algo_version` 을 꼭 남긴다. 이번에 지수를 고쳤을 때(학생 증감 제거) 예전 점수와 뒤섞이면
왜 순위가 바뀌었는지 설명할 수 없다.

### A-2. 졸업생의 진로 현황(진학률) — 경로 확정 (2026-09-28)

사용자가 인스타 카드 두 장을 보내와서 확인한 결과.

**OpenAPI 에는 없다.** 고등학교(schulKndCode=04) 용 apiType 은 26개뿐이고
(0,10,16,17,18,20,21,22,30,34,38,43,44,51,55,56,59,61,62,63,64,67,68,73,90,94),
2024·2025·2026 공시년도를 전부 훑어도 진학률 항목이 없다. '공개용 데이터' 일괄 파일에도 없다.
예전에 진학률로 착각했던 `TOTAL_RATE=100.0` 은 apiType 51 = **학업중단 현황**이다.

**웹 공시정보에는 있다. 공시항목 코드 06 '졸업생의 진로 현황'.**
지역별 공시정보(`/ei/ss/pneiss_a05_s0.do`)에서 학교급을 **고등학교로 바꿔야** 목록에 나타난다
(초등학교 기본값에는 없어서 없는 줄 알았다).

    1) POST /ei/ss/pneiss_a05_s0/selectSchoolListLocation.do
       HG_JONGRYU_GB=04(고)/03(중), SIDO_CODE=<시도2자리>00000000,
       SIGUNGU_CODE=<시군구5자리>00000, SULRIP_GB=1&2&3, GS_HANGMOK_CD=06, JG_HANGMOK_CD=52
       -> JSON schoolList: SHL_IDF_CD(uuid), SHL_NM, SHL_CD, ADDR_CD_ID(법정동), SHL_ROAD_NM_ADDR
       ※ SHL_CD 'B100000565' 의 뒷자리는 OpenAPI SCHUL_CODE 'S010000565' 와 같다 -> 매칭 열쇠
    2) POST /ei/pp/Pneipp_b06_s0p.do
       SHL_IDF_CD, GS_HANGMOK_CD=06, GS_BURYU_CD=JG040, JG_BURYU_CD=JG130, JG_HANGMOK_CD=52,
       GS_HANGMOK_NO=13-다, JG_YEAR=2025, JG_CHASU=4, adminYN=N, LOAD_TYPE=single
       -> HTML 표. '합 계' 행에서 졸업자, '비 율' 행에서 비율.

**나오는 값**
  - 고등학교: 전문대학 / 대학교 / 국외진학 / 취업 / 기타 (%)
  - 중학교:  일반고 / 특성화고 / **특수목적고** / **자율고** / 기타 (%)

**검증**: 화곡고 2025 공시 = 대학 43.6%, 전문대 21.8% (합 65.4%).
인스타 카드(굿-데이터, "25년 공시")의 화곡고 65.4% 와 일치. 출처 확정.

**캡챠**: `#popCapcha` 는 **첨부파일 다운로드에만** 걸려 있다. 표 조회 경로에는 없다.

**차단**: 2026-09-28 조사 중 연속 요청을 하자 `selectSchoolListLocation.do` 가
"서비스 일시 중단 안내" HTML 을 돌려주기 시작했다(브라우저에서도 동일). 메인 페이지는 정상.
**우회하지 않는다.** `fetch_advance.py` 는 요청 간격 1.2초 기본, 받은 학교는 다시 안 받고,
하루 예산만큼만 돌게 되어 있다. 차단이 풀렸는지 먼저 한 건으로 확인하고 시작할 것.

**쓸 때 주의 (중요)**
  - 진학률이 높다고 좋은 학교가 아니다. 특성화고는 취업이 목적이고, 예고는 국외진학이 섞인다.
    **일반고끼리만** 비교해야 한다(HS_KND_SC_NM = '일반고등학교').
  - 아파트에 붙일 때 고교는 배정이 추첨/광역이라 단지와 1:1로 안 묶인다.
    **중학교 쪽(특목고·자율고 진학률)이 단지 배정 중학구와 묶여서 훨씬 쓸모 있다.**

### A-3. 하지 않는 것 — 대학 합격 실적 집계

사용자가 '2026 서울대 합격 고교 TOP 20'(briefly.official) 카드도 보내왔다.
카드 하단에 출처가 **"베리타스알파 2026학년도 최종 합격실적 집계 기준 ·

이건 공공데이터가 아니라 **한 언론사가 직접 취재해 만든 자기 데이터베이스**다.
우리 사이트로 옮겨 싣는 건 저작권·데이터베이스권 문제이고, 그 매체 기사를 긁는 크롤러와

대학별 합격자 수는 공시 항목이 아니라서 공공데이터로는 애초에 구할 수 없다.
우리가 정당하게 쓸 수 있는 건 위 A-2 의 공시 진학률까지다.

|---|---|
