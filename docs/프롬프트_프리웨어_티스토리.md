당신은 무료 소프트웨어·웹 서비스를 소개하는 블로그의 글쓴이입니다.
아래 **확정 사실**만 사용해 한국어 소개 글 한 편을 작성하세요.

## 확정 사실 (이 내용 외에는 쓰지 말 것)
- 서비스명: 집콕맵 / 주소: https://jipkokmap.kr
- 무료. 설치 없음, 회원가입 없음, 로그인 없음. 웹 브라우저에서 바로 실행되며 휴대폰에서도 동작한다.
- 홈 화면에 추가하면 주소창 없이 앱처럼 열린다(PWA).
- 서울 아파트 6,809개 단지의 정보를 지도 한 장에 표시한다.
- 주요 기능:
  - 국토교통부 실거래가와 전세가율
  - 공식 학구도 기준 배정 초등학교, 통학 거리, 학급당 인원
  - 동네 학원비: 교육청 공시 교습비로 계산한 반경 1km 입시·보습 학원 월 교습비 중앙값 (강남구 36만원, 강북구 19.8만원)
  - 예산 대비 학군: 같은 가격대 단지들 안에서의 학군 순위
  - 출퇴근 시간: 회사 근처 역을 넣으면 지하철 소요 시간 계산, 맞벌이 두 곳 동시 조건 가능
  - 공사 중 지하철 노선과 예정역 도보권 표시
- 데이터 출처: 국토교통부, 교육부 학교알리미, 한국교육시설안전원 학구도안내서비스, 나이스 교육정보 개방포털, K-apt, 서울시 열린데이터광장, 오픈스트리트맵
- 계산 방식 공개 페이지: https://jipkokmap.kr/guide.html

## 글의 형식
- 제목: "무료"와 용도가 드러나게. 예) "설치 없이 쓰는 무료 서울 아파트 학군·학원비 지도 - 집콕맵"
- 분량: 공백 포함 1,200~1,800자
- 구성: (1) 어떤 사람에게 필요한 도구인지 → (2) 주요 기능 목록 → (3) 사용 방법 3~4단계 → (4) 휴대폰에서 앱처럼 쓰는 법(홈 화면에 추가) → (5) 데이터 출처와 한계
- 기능은 불릿으로 정리하고, 사용 방법은 번호 목록으로 작성

## 반드시 지킬 것
- **위 확정 사실에 없는 기능, 숫자, 화면 설명을 만들어내지 말 것.**
- 다운로드 파일이나 설치 프로그램이 있는 것처럼 쓰지 말 것. 웹에서 바로 쓰는 서비스다.
- "최고", "1위", "완벽한" 같은 과장 표현 금지.
- 부동산 시세 전망이나 투자 권유로 읽힐 문장 금지.
- 마지막에 한계를 적을 것: 서울만 지원(경기·인천 미지원), 실거래 신고가 최대 30일 지연될 수 있음, 학원비는 교습비를 공개한 학원만 집계, 매매 판단 전 현장과 등기부 확인 필요.
- 링크는 위에 적힌 주소만 사용할 것.
